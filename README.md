# 🐾 Biodiversity Finder App

Interactive Streamlit application for exploring biodiversity through a visual, natural-language species encyclopedia.

The app consumes the artifacts generated by `biodiversity-finder-training` and turns them into an interactive search experience with species cards, images, charts, conservation badges, and maps.

## ✨ Main Features

- Natural-language "vibe" search.
- `df.loc`-style filtering using generated tags.
- TF-IDF semantic ranking.
- Visual species cards with images.
- Narrative sighting descriptions.
- Conservation status badges.
- Highlighted warning for threatened species.
- Folium map with occurrence points.
- Plotly EDA charts.
- Offline light dataset mode.

---

## 🧠 Natural Language to Query

The app translates phrases such as:

```text
un bicho pequeño que vive en el desierto
```

into structured tags:

```text
size_tag = small
habitat_tag = desert
group = insect
```

and applies Pandas-style boolean masks:

```python
df.loc[mask]
```

## 🌱 Conservation and Ethics

The app displays conservation information when available:

```text
conservation_status
conservation_category
is_threatened
conservation_note
```

Threatened or sensitive species are visually highlighted.

Important limitation:

```text
The app is an educational tool and does not replace official ecological or conservation assessments.
```

## 📴 Offline Mode

Offline mode uses prepared lightweight artifacts:

```text
data/offline/species_encyclopedia_light.parquet
data/offline/species_occurrence_points_light.parquet
```

Activate it with:

```bash
OFFLINE_MODE=true streamlit run app.py
```

Offline mode means that the app uses a local prepared dataset. It does not mean the app can download new GBIF, Wikidata, or climate data without Internet.

```bash

cd biodiversity-finder-app
python -m venv .venv
source .venv/Scripts/activate

pytest
```
